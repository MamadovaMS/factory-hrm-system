# HRM System (Управление кадрами и расчет заработной платы)

Информационная система для автоматизации кадрового учета и расчета заработной платы сотрудников предприятия.

## 📝 Описание
Приложение предназначено для ведения учета личных дел сотрудников, управления структурными подразделениями и автоматизации бухгалтерских расчетов. Проект реализован с разделением логики на слои (Models, Controllers, Views).

## ⚙️ Основной функционал
* Ведение базы данных сотрудников и отделов.
* Автоматизированный расчет заработной платы (с учетом окладов, надбавок и вычетов).
* Формирование отчетов.
* Валидация вводимых данных и обработка ошибок.

## 🛠️ Стек технологий
* **Язык:** C# (.NET)
* **База данных:** MS SQL Server / SQLite 
* **Архитектура:** MVC / Слоистая архитектура (Models, Controllers)
* **UI:** Windows Forms / WPF

## 🚀 Инструкция по запуску
1. Разверните базу данных 
2. Откройте решение (файл `.sln`) в Visual Studio.
3. Проверьте строку подключения к базе данных.
4. Соберите и запустите проект.
